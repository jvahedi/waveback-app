Privacy policy

waveback is a personal tool used only by its owner, on the owner's own computer.

What it accesses

With the owner's permission, waveback reads the owner's Gmail messages and, when the owner approves a specific reply, sends that reply from the owner's account. It uses Google Cloud Pub/Sub only to be notified that new mail has arrived.

Where the data goes

Everything waveback reads is stored only on the owner's computer. It is not sold, shared, or transferred to anyone. The owner may use an AI model to help judge and draft replies; nothing is used for advertising.

Use of Google user data

waveback's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke waveback's access at any time at myaccount.google.com/permissions and delete its local data.
